## 📚 Data Analyst Skill Areas

| 🧩 Skill Area | Description | Tools Used |
|---|---|---|
| 🧹 **Data Cleaning** | Handling missing values, removing duplicates, fixing inconsistencies, standardising formats | Python (Pandas), Excel, SQL |
| 🔧 **Data Manipulation** | Reshaping, merging, aggregating and transforming datasets for analysis | Pandas, SQL (JOINs, CTEs, Window Functions), Power Query |
| 🏗️ **Data Modelling** | Building star/snowflake schemas, defining relationships, dimensional modelling | Power BI (Data Model), SQL, DAX |
| 📊 **Data Visualisation** | Creating dashboards, charts and reports to communicate insights clearly | Power BI, Matplotlib, Seaborn, Plotly, Excel Charts |
| ⚙️ **Data Engineering** | Building pipelines, automating data ingestion, transforming raw data | Python, SQL, ETL processes |
| 🔍 **Exploratory Data Analysis (EDA)** | Profiling data, identifying patterns, outliers and distributions | Pandas, NumPy, Jupyter Notebooks |
| 📐 **Statistical Analysis** | Descriptive stats, hypothesis testing, correlation, regression analysis | Python (SciPy, Statsmodels), Excel |
| 🤖 **AI in Data Workflows** | Leveraging AI tools to automate repetitive tasks, generate code and speed up analysis | ChatGPT, GitHub Copilot |
